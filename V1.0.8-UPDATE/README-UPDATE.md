## **INSTALACIÓN**

### **Para Versión Web**
1. Copiar todos los archivos al servidor web
2. Mantener la estructura de carpetas
3. Abrir `index.html` en el navegador

### **Para Versión Escritorio**
1. Usar los archivos en carpeta `electron/`
2. Ejecutar `npm run electron` o el ejecutable
3. La app se actualizará automáticamente
